# grill-to-implementation

Grill a change, persist decisions and execution state, then implement and independently review it without creating a SPEC or tickets.

## OpenCode V2 invocation

Invoke explicitly with:

```text
/grill-to-implementation
```

This skill is intentionally hidden from model auto-discovery/auto-invocation via `metadata.opencode/autoinvoke: "false"` while remaining available in the slash catalog.
