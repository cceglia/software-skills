# my-improve-spacing

Improve logical blank-line spacing with batched editing subagents.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-improve-spacing/` (project) or `~/.claude/skills/my-improve-spacing/` (global). Invocation: explicit only: `/my-improve-spacing`.
