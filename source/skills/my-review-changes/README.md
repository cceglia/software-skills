# my-review-changes

Review a specified set of modified files, or the current working-tree changes, using one independent read-only review subagent.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-review-changes/` (project) or `~/.claude/skills/my-review-changes/` (global). Invocation: explicit only: `/my-review-changes`.
