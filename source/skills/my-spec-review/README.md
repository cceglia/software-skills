# my-spec-review

Loop an independent fresh review of a spec and its issues, fix every problem, and stop only when a new review finds none.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-spec-review/` (project) or `~/.claude/skills/my-spec-review/` (global). Invocation: explicit only: `/my-spec-review`.
