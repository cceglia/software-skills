# asd-ste100

Set the ASD-STE100 response style for the session.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/asd-ste100/` (project) or `~/.claude/skills/asd-ste100/` (global). Invocation: explicit only: `/asd-ste100`.

```text
/asd-ste100                 ask level and scope
/asd-ste100 60 docs         level 60, replies and in-chat documents
/asd-ste100 replies         replies only, keep the level
/asd-ste100 help            show the level table
/asd-ste100 status          show the active level and scope
/asd-ste100 off             deactivate
```
