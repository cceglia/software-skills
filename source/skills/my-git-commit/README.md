# my-git-commit

Git commit all project changes except ephemeral ./.agents/tmp state. Never amends.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-git-commit/` (project) or `~/.claude/skills/my-git-commit/` (global). Invocation: explicit only: `/my-git-commit`.
