# my-golang-codebase-design

Reshape Go packages into deep modules: a narrow facade over `internal/<domain>`, one package at a time, behind an allowlist gate.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-golang-codebase-design/` (project) or `~/.claude/skills/my-golang-codebase-design/` (global). Invocation: explicit only: `/my-golang-codebase-design`.
