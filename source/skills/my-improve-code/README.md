# my-improve-code

Improve comments/documentation and logical spacing with batched editing subagents, without changing behavior.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-improve-code/` (project) or `~/.claude/skills/my-improve-code/` (global). Invocation: explicit only: `/my-improve-code`.
