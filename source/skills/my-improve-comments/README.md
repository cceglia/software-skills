# my-improve-comments

Improve code comments and documentation with batched editing subagents.

This directory is the **canonical Claude Code source**. Run `python3 scripts/build.py` from the repository root and install the generated profile with the installer.

Installed at `.claude/skills/my-improve-comments/` (project) or `~/.claude/skills/my-improve-comments/` (global). Invocation: explicit only: `/my-improve-comments`.
